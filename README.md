# 食品风险批次追召

本项目保存食品风险批次追召所需的领域上下文和校验契约，并在此基础上提供一个可运行的追召领域服务，便于围绕真实业务参与方演示“按批次追、按渠道召、按证据结”。数据均为演示用虚构内容，仅依赖 Python 标准库。

## 参与方

市场监管人员、生产企业、中间商、平台渠道

## 事实资料

- 报道披露假核桃油以普通大豆油灌装并贴不同标签销售
- 抽检发现棕榈酸含量异常并启动核查处置
- 案件需要从直播销售追溯到偏僻民房生产窝点和多级分成链

## 领域模型（五项约束）

代码位于 `src/food_recall/model.py`：

1. **批次谱系**：原料批 → 生产批 →（一个批拆成多个）灌装/包装批 → 标签 → 订单 → 渠道/销售主体。原料或标签来源异常时，沿谱系计算**真实受影响范围**，同品牌但谱系不相关的合格货（演示中的 PKG-C）不会被查封。
2. **抽检证据**：抽样、封存、复检、销毁/放行等每个决定都写入证据链并记录责任人；`open_package()` 一次返回风险依据、实际去向、已控制数量和决定清单。
3. **召回守恒**：每条包装批恒等校验
   - `产量 = 在库 + 出货`
   - `出货 = 退货 + 销毁 + 复检放行 + 未追回`
   - 多渠道回报合并扣减；**同一平台回执号幂等**，不重复扣减；内容矛盾则挂起该渠道并禁止结案；超量回报直接拦截。
4. **复检权限**：抽检人员不能批准（也不能作出）自己抽样的复检；复检期限按自然日计算，系统停机不顺延，恢复后催办按应发日期补推，逾期进入超期程序。
5. **跨区协同**：跨地区订单自动登记为跨区流向，须上级协调异地监管部门后才能清除结案障碍。

`src/food_recall/scenario.py` 是虚构演示情景（大豆油冒充核桃油、多标签、中间商 + 直播渠道），`src/food_recall/cli.py` 提供命令行总览。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

## 编译

```bash
python3 -m compileall -q src tests
```

## 命令行检查

领域资料摘要：

```bash
python3 -m src.food_recall.context fixtures/context.json
```

追召演示总览（风险依据、守恒账、结案障碍、证据链）：

```bash
python3 -m src.food_recall.cli
```

可选情景开关，可组合使用：

- `--conflict`：同一直播回执报送不同数量，演示渠道挂起
- `--retest`：演示抽检人回避、他人批准、停机后期限不顺延与催办补推
- `--coordinate`：由上级协调岭东市异地控制

```bash
python3 -m src.food_recall.cli --conflict --retest --coordinate
```
